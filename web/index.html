02 / HOW IT WORKS

One clean loop.

ACOB stays intentionally boring: standard requests in, JSON results out, and SQLite keeping the handoff reliable.

01
POST /api/browsers/:bid/instructions/

The agent sends an instruction

Submit a tab operation or JavaScript payload over ordinary HTTP.

02

The extension claims the work

Chromium polls its own queue, takes the oldest instruction, and executes it.

03
200 { "status": "completed" }

The result comes back as JSON

Poll the instruction ID and consume a predictable, serializable response.

03 / QUICKSTART

Browser control in minutes, not migrations.

Run the tiny Django server, load the unpacked extension, and send your first instruction. ACOB has no frontend runtime and no service account to configure.

  2. 2

  3. 3

Read the full setup guide 
# Install the Python dependencies
uv sync

# Prepare the local instruction queue
uv run manage.py migrate

# Start ACOB on its default port
uv run manage.py runserver 127.0.0.1:58347
# List every tab in the target browser
curl -X POST \
  http://127.0.0.1:58347/api/browsers/$BID/instructions/ \
  -H 'Content-Type: application/json' \
  -d '{"action":"tabs","operation":"list"}'
